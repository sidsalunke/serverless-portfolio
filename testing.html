Stage 02

Post-deployment.

After the site goes live, a second quality gate runs against the real CloudFront distribution — with automatic rollback if anything regresses.

Live E2E Smoke Tests

The full Playwright suite re-runs against the live CloudFront URL after each deploy. The pipeline waits for the CDN invalidation to complete first — ensuring tests always exercise the freshly deployed content, not stale cache.

Playwright CloudFront post-deploy gate
Lighthouse CI

Three Lighthouse runs are averaged against enforced score thresholds: Performance ≥90, Accessibility 100, Best Practices 100, SEO 100. Results feed the metric badges committed back to the repo.

Perf 90+ · A11y 100 · SEO 100
lhci autorun score thresholds
Auto-Rollback

If live E2E tests fail, a rollback job automatically restores the previous commit to S3 and invalidates the CDN — users see the last known-good version within minutes, with no manual intervention.

canary gate S3 restore zero-touch
Metric Badges

Coverage and Lighthouse score badges are generated as SVGs and committed back to master with [skip ci] on every successful deploy. No third-party badge services — everything self-hosted.

SVG badges badge-maker self-hosted
